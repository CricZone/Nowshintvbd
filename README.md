# 📺 NowshinTV Admin Panel

NowshinTV Admin Panel is a lightweight, ultra-modern, serverless IPTV Channel Management Dashboard. Built as a single-page application (SPA), it interfaces directly with a cloud-based architecture via REST API to monitor, create, update, and sort live streams dynamically. 

Featuring a fully responsive design, Progressive Web App (PWA) installation parameters, smart shifting sort mechanisms, and immediate visual network diagnostic queues.

---

## ✨ Features

*   **⚡ Serverless Cloud Architecture:** Seamlessly connects to a fast cloud database infrastructure via a custom asynchronous REST API engine.
*   **📶 Real-time Status Monitoring:** Instantly identifies operational and offline feeds using localized network visualization indicators.
*   **🔀 Smart Serial Shifting:** Intelligent index management—automatically increments subsequent channel row indexes when inserting configurations into an existing position.
*   **📱 Progressive Web App (PWA):** Features an embedded Base64 JSON manifest configuration allowing users to install the dashboard locally on iOS, Android, and Desktop environments.
*   **🌓 Unified Dark Theme Engine:** Advanced, low-fatigue UI optimized for system-wide performance with instant theme persistence states.
*   **🔍 High-Fidelity Query Filtration:** Client-side asynchronous index searching that filters names, categories, and source links instantly across mobile and desktop wrappers.

---

## 🛠️ Tech Stack

*   **UI Architecture:** HTML5, Tailwind CSS Engine (v3.x), Plus Jakarta Sans Typography.
*   **Dynamic Engine:** Vanilla ECMAScript 6+ (Async/Await Fetch Infrastructure).
*   **Database Routing:** Serverless Google Apps Script Executable Endpoints.
*   **Manifest Integration:** Base64 Standalone Inline PWA Framework.
